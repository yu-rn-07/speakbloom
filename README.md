# SpeakBloom｜オンライン英会話サービス LP

## 概要

SpeakBloomは、英会話初心者向けの架空オンライン英会話サービスのランディングページ（LP）です。

「英語を、30日で『続く習慣』に。」をコンセプトに、1日15分の短時間レッスンや7日間の無料体験を紹介するサイトとして制作しました。

ユーザーがサービス内容を理解し、無料体験の申し込みまでスムーズに進められる構成を意識しています。

※ 本サイトはポートフォリオ用の架空サービスです。実際の申し込み受付は行っていません。

## 実装した機能

### 1. レスポンシブデザイン

- PC・スマートフォンに対応
- CSSのFlexbox・Gridを活用したレイアウト
- スマートフォン用ハンバーガーメニュー

### 2. レッスン紹介のタブ切り替え

- JavaScriptによる表示内容の切り替え
- 選択中のタブを視覚的に区別

### 3. 利用者の声スライダー

- JavaScriptによるスライド操作
- PCでは3件ずつ、スマートフォンでは1件ずつ表示
- ページ位置を示すドット・カウンターの切り替え

### 4. FAQアコーディオン

- 質問をクリックすると回答が開閉
- 開閉状態に応じた「＋／−」表示
- `aria-expanded`による開閉状態の管理

### 5. 無料体験申し込みフォーム

- 氏名・メールアドレスなどの入力項目
- HTML標準のバリデーション
- ラジオボタン・チェックボックスの実装
- JavaScriptによるデモ送信完了メッセージの表示
- 完了メッセージへのスムーズスクロール

※ フォームはデモ仕様であり、データの送信・保存は行いません。

### 6. 利用規約ページ

- `terms.html`による別ページの作成
- トップページとのデザイン統一
- スマートフォン表示への対応

## 制作で工夫したポイント

**ユーザーが迷わず操作できるUI**

サービス紹介から料金プラン、無料体験申し込みまで、情報を順番に確認できるページ構成にしました。

**スマートフォンでの使いやすさ**

画面幅に応じてレイアウトを変更し、メニュー・カード・スライダー・フォームが操作しやすいように調整しました。

**フォーム送信後の分かりやすさ**

送信後にデモ完了メッセージを表示し、その位置まで自動スクロールすることで、操作結果に気づきやすいように工夫しました。

**JavaScriptによるインタラクション**

ライブラリに依存せず、JavaScriptでタブ・スライダー・アコーディオンなどを実装しました。

## 制作目的

HTML・CSS・JavaScriptの学習成果を形にし、実際のWeb制作を想定したLP制作のスキルを身につけるために制作しました。

デザインの実装だけでなく、レスポンシブ対応、操作性、フォームの入力チェック、公開後の動作確認まで一通り取り組みました。
